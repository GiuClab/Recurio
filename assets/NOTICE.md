# Recurio artwork

Logo created for GiuClab using image generation, approved in the project conversation, based on the GiuClab/VisiLens family style. WebP derivatives are resampled from that selected logo, with no redesign. Recurio artwork is distributed under the project GPL-3.0-or-later license to the extent applicable. The GiuClab and third-party marks do not imply third-party affiliation or endorsement.

Android adaptive foreground uses the same mark centered with safe padding on a transparent canvas; its background is GiuClab blue #385AD0. Legacy launcher sizes and in-app artwork use the same approved icon.
